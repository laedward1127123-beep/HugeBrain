# HugeBrain

一个将**脑区、认知功能、实验范式与文献证据**连接起来的交互式研究工作空间。前端以 HTML、CSS 和 Three.js 构建，采用受 Liquid Glass 启发的透明玻璃界面；后端使用 Python 标准库与 SQLite 保存结构化文献。

## 快速开始

环境要求：

- **Node.js**：建议使用 22.12 或更高版本；当前 Vite 的版本要求为 `^20.19.0 || >=22.12.0`。
- **Python 3.10+**：应用运行仅使用标准库，无须安装 Python 第三方依赖。
- 支持 WebGL 的现代浏览器。

在项目目录运行：

```sh
npm install
npm run build
npm start
```

打开 **[http://127.0.0.1:8000](http://127.0.0.1:8000)**。

首次启动会自动建立 `data/hugebrain.db`，写入脑区注册表与 9 篇真实文献的示例记录。之后的启动保留已有数据。实际脑表面资源已经包含在仓库中；正常运行无须下载图谱、安装 FreeSurfer 或连接外部字体服务。首次安装前端依赖需要网络，打开论文原始来源也需要网络。

界面通过本地服务访问，不能直接双击 `index.html` 使用数据库功能。默认服务仅监听本机。

## 可以做什么

- **探索真实 a2009s 图谱**：显示 FreeSurfer fsaverage5 上的 Destrieux 分区，左右半球共 148 个可选择皮层分区；支持旋转、缩放、半球与视角切换，以及皮层／膨胀表面切换。
- **从脑区读取证据**：选择脑区，查看相关论文、实验范式、研究发现、机制解释、指标、标签以及映射依据。
- **播放统一风格的研究动画**：以一致的视觉语言呈现记忆、注意、语言等实验步骤，以及解码、激活和表征关系等指标示意。
- **从认知功能观察脑区**：右侧功能导航驱动脑表面热图，按当前数据库中关联该功能的独立文献数着色。
- **管理文献**：按关键词、年份、研究方法或认知功能检索；通过表单添加文献，或导入完整 JSON 记录以保存更详细的实验、发现与标签。支持 JSON 导出。
- **区分映射审核状态**：每项发现保存映射来源、信心水平和 `provisional` / `accepted` 状态，界面可只显示已确认映射。

## 数据与证据边界

脑表面与解剖标签使用真实数据，保留原始 a2009s 标签索引；例如 `lh_45` 是左侧 `S_calcarine`，`42` 是不可选择的 medial wall。数据来源、处理流程、校验值和授权说明见 [图谱来源说明](docs/atlas-provenance.md) 与 [资源清单](public/data/atlas-manifest.json)。

随附的 9 篇文献用于演示知识组织方式，并非系统综述。它们包含 21 条发现，全部解剖对应均标为**待复核**：原论文的功能定位或 ROI 不自动等同于 a2009s 解剖分区。距状沟不能直接视为个体 V1 功能掩模；此皮层图谱也不包含海马等皮层下结构。认知功能菜单中的情景记忆目前没有示例文献。

热图使用 `COUNT(DISTINCT paper_id)`：同篇论文在同一脑区的多个实验或发现只计一次。颜色表达**文献覆盖度**，不能据此推断效应量、证据质量或功能特异性。切换到“仅已确认的脑区映射”后，初始示例库会显示零条关联，这是审核状态的真实反映。

实验动画、曲线与矩阵均为教学示意，时序和数值不取自原始测量。未从原文逐项提取的样本量和统计量保持空值。逐篇来源与解释限制见 [示例文献说明](docs/evidence-sources.md)。

## SQL 数据与导入

SQLite 数据库存放在 `data/hugebrain.db`，数据库及其 WAL 文件已加入 Git 忽略规则。关系模型包括：

```text
文献 ── 实验 ── 研究发现 ── 脑区
 │                  │
 └── 分类标签        └── 认知功能
         实验与发现 ── 动画参数
```

每个发现独立记录指标、结果方向、证据性质、解剖映射状态、映射依据与局限性。标签可涵盖领域、范式、模态、人群、刺激、设计、分析方法、指标、来源和审核状态，也支持自定义分类。

- [SQL 建表文件](database/schema.sql)
- [完整数据模型、字段示例与 API 文档](docs/data-model.md)
- [示例 JSON 数据](database/seed.json)

在“数据管理”中可以导入完整记录或导出整个文献库。单篇文章导入为一个事务：重复 DOI、ID 冲突或无效关联会拒绝该篇，且不会留下不完整记录。批量导入逐篇处理，并非跨全部文章的总事务；导出文件里的 `papers` 数组可以用于重新导入，已有记录会报告重复。

当前网页提供新增、检索、导入和导出；尚未提供逐字段编辑、删除或人工审核工作流。需要录入完整实验和发现时使用 JSON；改变已存记录可通过 SQLite 工具操作，并先做好备份。数据库结构与 API 不会自动替代文献提取和人工复核。

## 开发与验证

开发时先启动 API 服务：

```sh
npm start
```

另开一个终端启动前端开发服务：

```sh
npm run dev
```

打开终端输出的 Vite 地址，通常为 [http://127.0.0.1:5173](http://127.0.0.1:5173)。前端将 `/api` 请求代理至本机 8000 端口。

运行测试与构建：

```sh
npm test
npm run build
```

测试覆盖独立文献去重、映射状态筛选、同一发现上的脑区／功能联合过滤、实际示例数据导出重导入、持久化、外键约束、无效输入、重复 DOI、事务回滚和静态资源路径边界。测试使用临时数据库，不改动工作空间中的文献库。另有 8 项动画科学一致性测试，验证范式阶段、RDM 不变量、记忆负荷横轴及未知指标的中性展示。

可指定其他端口与数据库文件：

```sh
python3 server.py --port 8001 --db data/my-research.db
```

如修改开发环境 API 端口，同时更新 `vite.config.js` 中的代理目标。

## 可选：重新生成图谱资源

常规启动无需此步骤。需要重新生成时，安装转换脚本依赖并执行：

```sh
python3 -m venv .venv-atlas
source .venv-atlas/bin/activate
python3 -m pip install -r scripts/atlas-requirements.txt
python3 scripts/prepare_atlas.py
```

转换脚本从固定来源下载输入，验证 SHA-256，检查网格与分区一致性，生成浏览器使用的 JSON。原始输入缓存于 `.cache/atlas`。完整流程见 [图谱来源说明](docs/atlas-provenance.md)。发布生成资源时须保留 [FreeSurfer](public/data/licenses/FreeSurfer-LICENSE.txt) 与 [Nilearn](public/data/licenses/Nilearn-LICENSE.txt) 的授权声明。
